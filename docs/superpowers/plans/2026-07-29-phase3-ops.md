# Phase 3 — Platform Ops Implementation Plan

> **For agentic workers:** Use executing-plans / TDD. Checkbox steps.

**Goal:** Superadmin ops for multi-school: platform audit trail, simple org health on the schools list, orgSettings backup export, and block school users when their org is suspended.

**Architecture:** Separate `platformAuditLogs` (not lead `auditLogs`). Pure helpers for action labels, health band, and export payload shape. Client services write audits on create/suspend/reactivate/export. OrganizationsView shows health counts + recent audits. ProtectedRoute (or small hook) loads `organizations/{orgId}.status` for school users.

**Tech Stack:** React, Firestore, Vitest, existing bento UI + `downloadJsonFile`.

## Global Constraints

- Platform super_admin only for ops UI / writes that mutate org status.
- Vietnamese plain-language copy (no collection names in end-user UI).
- Suspend already exists — harden with audit + login gate; no full billing.
- Skip full lead dump backup (YAGNI); export **orgSettings** JSON only.
- `npm test` + `tsc`/`build` green before claiming done.
